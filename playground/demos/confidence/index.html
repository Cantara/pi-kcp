The Confident Fool

An answer the model isn't sure of shouldn't ship as if it were certain. The confidence gate halts a shaky conclusion for a second opinion — deterministically, at a declared threshold. It runs downstream of synthesis: confidence is a property of the output. The model's self-report is only a proposal; the gate adjudicates with pure code — score >= threshold, fail-closed. The verdict is computed by the real assess() gate logic from kcp-agent, and signed & verified with genuine crypto.subtle in your browser.

Dial in a self-reported confidence and the caller's threshold, then press ▶ Assess conclusion. Drop below the line and watch the printer halt the answer for a second opinion.
